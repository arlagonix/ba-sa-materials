# Иерархия и классификация технологий интеграции

- **Дата**: 28 мая, четверг, 18:00 мск
- **Спикер**: Андрей Бураков, Tech Product Manager

Приглашаем на открытый вебинар, где предложим вариант классификации технологий, который поможет выстроить в голове понятную систему. А если вы не согласны с чем-то, то с удовольствием похоливарим.

В формате диалога разберем:

- Иерархию сетевых протоколов и модель OSI
- Протоколы TCP, UDP, TLS
- Работу HTTP/1, HTTP/2, HTTP/3, Websockets
- Уровни зрелости REST API
- RPC-style API: SOAP, JSON-RPC, GraphQL
- Message Brokers

Зачем это аналитику: чтобы обсуждать использование и выбор технологий взаимодействия, опираясь на актуальный контекст и задачи, а не абстрактные статьи и чек-листы.
